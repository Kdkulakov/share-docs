# answer-me-with-html: HTML и видео через Codex, Cursor или Claude Code

Сценарий работы: **установить skill → настроить ElevenLabs → попросить агента объяснить тему → попросить видео**.

Вы задаёте тему и пожелания в чате. Агент пишет сценарий, запускает инструменты skill, создаёт файлы и проверяет результат. Ниже — инструкция для macOS с zsh.

## 1. Установить skill

В терминале выполните команду для своего агента:

```zsh
# Codex
npx -y skills add QingYunA/answer-me-with-html --skill answer-me-with-html -g -a codex -y

# Cursor
npx -y skills add QingYunA/answer-me-with-html --skill answer-me-with-html -g -a cursor -y

# Claude Code
npx -y skills add QingYunA/answer-me-with-html --skill answer-me-with-html -g -a claude-code -y
```

Достаточно одной подходящей команды. `-g` устанавливает skill для пользователя, чтобы он был доступен в разных проектах. После установки откройте новую сессию агента.

Если `npx` не найден, попросите агента проверить установку Node.js и npm. При наличии Homebrew установить их можно командой:

```zsh
brew install node
```

Источник установки: [answer-me-with-html](https://github.com/QingYunA/answer-me-with-html), параметры: [skills CLI](https://github.com/vercel-labs/skills).

## 2. Попросить агента проверить зависимости

Отправьте в чат:

```text
Проверь установленный skill answer-me-with-html и зависимости
для генерации HTML и видео MP4. Используй уже установленные инструменты.
Если чего-то не хватает, объясни, что нужно установить и зачем.
```

Что использует skill:

| Задача | Что нужно на машине |
| --- | --- |
| HTML | Node.js 20+ |
| Озвучка ElevenLabs | API key, доступный голос и доступ к API |
| Экспорт MP4 | Node.js 22+ по документации skill, FFmpeg и поддерживаемый браузер |

**Как было у нас:** Chrome и FFmpeg уже были установлены. Codex использовал их сам; отдельно Chrome мы не устанавливали. Для экспорта агент задействовал существующий Node.js 20 с экспериментальной поддержкой WebSocket. Для новой установки проще использовать Node.js 22+.

Браузер нужен экспортеру, чтобы отрисовать кадры анимированной HTML-страницы; FFmpeg собирает их и звук в MP4. Открывать браузер вручную для этого не требуется. Для HTML-плеера без экспорта MP4 этот этап не нужен.

## 3. Добавить переменные ElevenLabs в `~/.zshrc`

В аккаунте ElevenLabs создайте API key с доступом к синтезу речи и скопируйте Voice ID выбранного голоса.

Откройте настройки zsh:

```zsh
nano ~/.zshrc
```

Добавьте три строки, подставив свои значения вместо заглушек:

```zsh
export ELEVENLABS_API_KEY='YOUR_API_KEY'
export ELEVENLABS_VOICE_ID='YOUR_VOICE_ID'
export ELEVENLABS_MODEL_ID='eleven_multilingual_v2'
```

Сохраните файл и примените настройки в текущем терминале:

```zsh
source ~/.zshrc
```

- `ELEVENLABS_API_KEY` — ключ доступа к API.
- `ELEVENLABS_VOICE_ID` — идентификатор голоса.
- `ELEVENLABS_MODEL_ID` — модель синтеза; в нашем рассказе использовали `eleven_multilingual_v2`.

Ключ вводите в редакторе, не вставляйте его в чат или файлы проекта. [API keys ElevenLabs](https://elevenlabs.io/docs/api-reference/authentication), [модели](https://elevenlabs.io/docs/overview/models).

## 4. Выбрать тему и получить HTML-ответ

Все примеры ниже — **сообщения в чате**, их не нужно выполнять в терминале.

В Codex начните запрос с `$answer-me-with-html`, в Claude Code — с `/answer-me-with-html`. В Cursor можно написать «Используй skill answer-me-with-html».

Если тему должен предложить агент:

```text
Используй skill answer-me-with-html.
Предложи три темы про MLOps, которые удобно объяснить схемами.
Я выберу одну, после чего подготовь наглядный HTML-ответ.
```

Если тема уже известна, как в нашем примере с Codex:

```text
$answer-me-with-html Расскажи на русском, как работает Model Registry
в GitLab. Опиши компоненты и их взаимодействие.
Используй примеры из текущего проекта и проверь факты по документации.
Подбери подходящую тему оформления и создай HTML со схемами.
Сохрани файл в проект и дай ссылку для открытия.
```

Чтобы добавить голос к странице:

```text
Добавь к HTML-объяснению русскую озвучку ElevenLabs и аудиоплеер.
```

Агент сам подготовит текст и встроит аудио. Озвучка обычной HTML-страницы — дополнительная работа агента; штатный режим озвучки skill предусмотрен для видео.

## 5. Попросить сгенерировать видео

В той же переписке после HTML-ответа:

```text
Теперь сгенерируй видео по этому объяснению с помощью
skill answer-me-with-html.
Сделай анимированные схемы и русскую озвучку ElevenLabs.
Сохрани MP4 и HTML-плеер. Проверь читаемость подписей и субтитров.
```

Можно уточнить пожелания:

```text
Сделай рассказ примерно на четыре минуты, из шести сцен.
Выбери тёмную тему оформления. Объясняй простыми словами.
```

Агент подготовит сценарий, озвучку, анимацию и экспорт. Вы получите ссылки на MP4 и HTML-плеер.

Для исправлений достаточно следующего сообщения:

```text
В третьей сцене субтитры перекрывают подписи.
Исправь компоновку и пересобери видео, переиспользуя готовую озвучку.
```

## 6. Если что-то не работает

| Ситуация | Что написать агенту |
| --- | --- |
| Skill не находится | «Проверь установку answer-me-with-html и путь к SKILL.md» |
| Нет озвучки | «Проверь подключение ElevenLabs, права ключа и доступ к голосу; не показывай ключ» |
| Получился только HTML | «Экспортируй также MP4 и проверь зависимости экспорта» |
| Не хватает браузера или FFmpeg | «Проверь уже установленные инструменты и предложи установку только недостающих» |
| Схема слишком мелкая | «Увеличь подписи, раздели схему на сцены и проверь кадры» |

Если среда агента отдельно запросит разрешение отправить текст в ElevenLabs, речь идёт о передаче текста рассказа внешнему сервису. В нашей переписке такое разрешение потребовалось для описания локального проекта.

Документация навыков: [Codex](https://developers.openai.com/codex/skills/), [Cursor](https://cursor.com/docs/skills), [Claude Code](https://code.claude.com/docs/en/skills).
